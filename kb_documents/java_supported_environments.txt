Splunk AppDynamics Java Agent supported environments reference.
Source basis: official Splunk/AppDynamics Java Supported Environments documentation.
Use this as a practical KB summary for Java Agent support checks around the 26.2/26.3 documentation family.

JVM support

- Sun HotSpot based JVMs: Oracle OpenJDK, Amazon Corretto, AdoptOpenJDK / Eclipse Temurin, BellSoft Liberica, Azul Zing/Zulu, RedHat OpenJDK, SapMachine, GraalVM.
  Supported Java versions: 8 to 25.
  Notes: OIT, CI, and AT require full JDK. CI and AT are not supported on Azul Zing. Graal Native Images are not supported.

- IBM J9 based JVMs: OpenJ9, IBM J9, AdoptOpenJDK (up to Java 16), Semeru.
  Supported Java versions: 8 to 21.
  Notes: OIT and AT are not supported. CI requires full JDK. Hybrid mode is not supported.

Important notes

- If a framework is not listed in the official support matrix, AppDynamics can still instrument the JVM, but automatic entry/exit discovery may require custom POJO entry points, custom exit points, or custom match rules.
- Some supported environments require node properties or extra configuration. Examples include Netty, Jersey/JAX-RS, WebSocket, Spring WebFlux, Quarkus RESTEasy Classic, and SOAP header correlation for some web service stacks.
- Servlet 3.x detection is explicitly noted as not supported in the application server section.
